## 📌 About the Project

This project is a web-based version of my personal resume.

I developed it while learning HTML5 and CSS3, using my own professional information as the content instead of creating a fictional website.

The project combines my academic background in Electrical Engineering with my interests and practical experience in programming, data analysis, automation, backend development, and technology.

It serves both as a personal resume and as a practical project for my web development portfolio.
